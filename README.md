# Digital Guidebook

A modular Airbnb guest site for hosts. Edit photos, Wi‑Fi, check-in, map, and house notes in the studio, then download a single HTML file to send guests.

## Use it

1. Open the studio (`index.html`).
2. Start from a template or a blank guidebook.
3. Change pictures (URL or upload) and the stay details.
4. Watch the phone preview on the right.
5. Click **Download HTML**. That file is self-contained and ready to email, AirDrop, or host.

Guides are saved in the browser (`localStorage`) so you can keep several properties.

## Samples

Static copies live under `samples/` if you want a fixed URL per listing.
